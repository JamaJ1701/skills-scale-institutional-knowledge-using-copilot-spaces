# OctoAcme Project Management Docs

## Overview of OctoAcme project management

OctoAcme runs cross-functional projects iteratively and customer-first. Each project has a named Project Manager and Product Lead, delivers small testable increments, and uses data to guide decisions.

Projects move through five stages:

1. **Initiation** – define the problem, stakeholders, success metrics, and a high-level timeline; decide go/no-go.
2. **Planning** – build a prioritized, estimated backlog, a Definition of Done, a release plan, and a risk register.
3. **Execution** – build, test, review, and iterate with daily standups, weekly syncs, small PRs, and CI.
4. **Release** – deploy through staging with smoke tests, a rollback plan, and stakeholder announcements.
5. **Close & Retrospective** – capture learnings and turn them into tracked action items.

Risks, dependencies, and communication are managed throughout, with escalation from team to PM to Product Lead to Sponsor.
